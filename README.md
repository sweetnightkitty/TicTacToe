# Tic Tac Toe Game

This project is a practice project that was built in accordance with the ODIN Project Tic Tac Toe assignment to practice working deeper with vanilla Javascript, HTML and CSS.

## The Development Process:

One major learning goal of this assignment was to apply the "Build a house from the inside out" approach, which meant focusing first on developing the game logic in Javascript before building the UI.

This proved to be challenging as I began first by utilizing a 2D array to represent the Tic Tac Toe board in the browser console, building on this logic to control the functionality of the gameboard under the hood. However, without any visual representations in the UI of the gameboard in these early stages I was forced to think more critically about my approach, and the code.

## Getting Started

Start by forking this repository, and then making a clone of your forked copy to your local environment and you're ready to go.

## Note on Responsive Design

This project was created before I learned about responsive design practices, depending on your screen size you may find that the tic tac toe board overflows at the bottom of the screen. If you encounter this simply using your computer's native zoom-out features should resolve this.

In the future, this is something that I hope to introduce into this project to eliminate issues viewing on different screen sizes as well as to make gameplay on mobile devices a possibility, too.
